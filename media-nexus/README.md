# 🎭 MediaNexus - Professional Multi-Service Media Hub

## Overview
MediaNexus ek all-in-one professional platform hai jo creators, artists, aur businesses ko multiple services provide karta hai:

### 🌟 Key Zones:
1. **🎵 Music Distribution** - Global music distribution to 150+ platforms
2. **📺 MCN Network** - YouTube creator network with brand deals
3. **🎬 Production Studio** - Professional video production services
4. **💍 Wedding & Events** - Cinematic wedding films and event coverage
5. **🚀 Brand Solutions** - Influencer marketing and brand campaigns
6. **🎙️ Podcast Studio** - Podcast recording and distribution

## Features
✅ Modern, responsive design with gradient backgrounds
✅ Interactive zone filtering system
✅ Contact form with modal popup
✅ Smooth animations and hover effects
✅ Mobile-friendly layout
✅ Professional UI/UX

## How to Use
1. Open `index.html` in any web browser
2. Browse different zones using the filter buttons
3. Click "Get Started" on any service to open the contact form
4. Fill in your details and submit
